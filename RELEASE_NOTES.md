# Release Notes

## New

- Limit bag, bank, and Warbank size with the new maximum-scale option; automatic shrinking still keeps them within the screen.
- Item insertion markers show before/after placement between icons and end placement over categories in bags, bank, and Warbank. Gaps between icons also accept item drops.

## Tweaks

- Category drops over category item areas now use consistent targeting in bags, bank, and Warbank.
- The MyBags settings entry now matches the addon title colours while keeping its alphabetical position.

## Bug fixes

- Leaving bank edit mode now prompts to save or discard unsaved category edits.
